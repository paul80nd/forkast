A small static label — cuisine, diet tags, allergens, "why" reasons, star/version overlays.

```jsx
<Tag>Italian</Tag>
<Tag tone="star">★★★★</Tag>
<Tag tone="info">variety</Tag>
<Tag tone="warn">unrated</Tag>
```

Tones: neutral / brand / star / info / warn / danger. Use `square` for the
FEATURED-style block label. Not clickable — use Chip for selectable pills.
