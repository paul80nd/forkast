A coloured wash feature panel — proposals and summaries.

```jsx
<Panel tone="info" title="Suggested week" subtitle="A proposal — nothing's added yet."
  actions={<Button variant="primary" size="sm">Accept 5 → week</Button>}>
  …slots…
</Panel>
```

Tones: **info** (suggested week / proposals), **brand** (versions / positive),
**warn** (attention), **neutral** (plain summary). Radius is 2xl.
